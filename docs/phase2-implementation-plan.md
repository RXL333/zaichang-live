# 第二阶段：会议核心体验

目标是在现有 Vue、Spring Boot、LiveKit Cloud 和部署方式上完善入会及会中体验，保留账号和会议数据。第一阶段的安全边界、测试和发布门禁继续适用。

1. M1：集中动效时长和缓动，监听系统减少动态设置，页面隐藏时停止首页演示计时器。
2. F5、E1：统一邀请文本及号码解析，离线生成二维码；会议页面和 LiveKit 按路由加载，输入完整号码时预取。
3. F1、F2：加入前仅在用户主动操作时检查设备，离开预览释放轨道；默认不开摄像头和麦克风。会中提供设备切换和断开提示。
4. F3、A3、F6：补充画廊／演讲者视图、固定、分页和独自在会引导；核对并完善聊天及音视频重连，显示真实连接质量。
5. A5、A6：为入会异常提供可继续操作的状态，在移动端提供底部侧栏和适配安全区的控制栏。
6. F4：先形成主持人控制的事件、字段、权限与回滚提案；按原方案在确认前不变更会议协议、鉴权或数据库表结构。

验证范围包括相关组件和逻辑测试、前端生产构建、后端 Maven 测试以及桌面与手机视口检查。真实摄像头、麦克风、设备热插拔、多人网络质量和带宽仅在确有设备与网络验证时记录为通过，否则标记待人工验证。发布前检查是否有正在进行的会议并保留回退方案。
