# 第三阶段：会议体验打磨

在现有 Vue、Spring Boot 和 LiveKit Cloud 架构上实施用户文档中的 P2 项目；保持默认静音入会，不改数据库、会话鉴权或 WebSocket 协议。第二阶段主持人控制仍以独立提案为准。A9 和第四阶段项目不在本轮范围。

1. A1、A2、A4：为会议号提供小型本地数字字体和系统回退；头像按用户 ID 稳定配色并验证对比度；完善会议列表的加载、状态与触屏操作。
2. M2、M3、M4：平滑说话状态、成员画面变化及工具按钮反馈，保持视频元素稳定并遵循减少动态设置。
3. F7、F8、M6、F9：增加离会结束页与最近加入记录；复用既有聊天历史接口，完善消息呈现、重发和滚动；增加未读提示及可键盘操作的快捷键。
4. M5、A10：补充大厅与入会页过渡、支持时的会议号共享过渡和状态读屏提示；会议室保持直接进入。
5. E2、E3：补足行为测试和 CI 冒烟测试；加入依赖更新与高危审计，并按当前后端和 LiveKit 域名配置内容安全策略。

每项随实现增加针对性测试并独立提交；阶段结束运行前端测试和构建、后端 Maven 测试及适当的浏览器检查。测试记录区分模拟、实际设备和线上服务。聊天历史现由后端保存并返回最近 200 条，不需要新增历史协议。音视频设备、真实多人会议、读屏与网络中断未亲测前不计为通过；内容安全策略的真实 LiveKit 连接也需实际验证。
