# 在线会议系统改造计划

## 目标与范围

在现有 Vue 3、Spring Boot、WebSocket、Neon、LiveKit Cloud、GitHub Pages 和 InstaBox 基础上，将直播站改为多人会议。按用户要求保留账号、清空旧直播测试记录并新建会议数据。会议 UI 使用成熟、暖中性色，重点满足教师的账号、会议管理、多人音视频、聊天、成员管理和远程访问要求。

## 实施顺序

1. 新增会议表和受密码保护的加入流程，沿用账号及会话；添加会议创建、查询、修改、删除、加入及成员身份校验。
2. 实现会议 WebSocket 连接、实时聊天、成员名单、昵称、主持人静音及移出，确保不同会议隔离和断线重连。
3. 用 LiveKit 允许所有参会者发布摄像头、麦克风及屏幕，关联成员身份；为 OBS 创建会议内专属的推流凭证并支持主持人管理。
4. 重做会议首页、入会流程和会议室页面，移除直播场景入口；兼容 GitHub Pages 和后端自带的前端入口。
5. 验证账号、权限、隔离、会议操作、构建和实际部署；更新文档，备份生产数据库后再部署后端与前端。

## 重要约束与验收

- 密码哈希存储；加入后的凭证绑定会议与登录会话，媒体和聊天均校验访问权限。会议号及邀请链接不含密码。
- 被移除成员的会议授权失效，并尽力断开媒体连接和 OBS 推流；异常不得报告为成功。
- 运行至少两间会议，验证消息、成员、媒体凭证和主持人权限互相隔离。验证真实浏览器设备及 OBS 的情况如实记录，不用模拟结果代替。
- 如现有云平台无法提供某项功能，明确列为未完成。LiveKit Cloud 暂时替代教师要求的自建流媒体服务器，不宣称该项已满足。
- 不更换当前免费平台；不向仓库提交生产凭据。发布前备份生产数据库，保留可回退方案。
